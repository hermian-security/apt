Hermian APT repository

Signed packages for Hermian. Suites: beta (prereleases and releases) and stable.

curl -fsSL https://apt.hermian.me/hermian-archive-keyring.gpg | sudo tee /usr/share/keyrings/hermian-archive-keyring.gpg >/dev/null
printf 'Types: deb\nURIs: https://apt.hermian.me\nSuites: beta\nComponents: main\nSigned-By: /usr/share/keyrings/hermian-archive-keyring.gpg\n' | sudo tee /etc/apt/sources.list.d/hermian.sources
sudo apt update && sudo apt install hermian

Or use the one-line installer from the README: it sets this up for you.
